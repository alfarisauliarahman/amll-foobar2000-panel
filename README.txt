AMLL foobar2000 Panel v0.2.0
================================

This is a WebView template, not a native .fb2k-component.

Required component:
https://github.com/stuerp/foo_uie_webview/releases

Installation:
Read INSTALL.md, install foo_uie_webview, add a WebView panel, select this
index.html as its template, and enable Read files.

Lyrics:
Place a .ttml file beside the audio file using the same basename.

Source code:
https://github.com/alfarisauliarahman/amll-foobar2000-panel
