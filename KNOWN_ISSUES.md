# Known Issues and Invariants

## Now-playing path is indirect

The current `foo_uie_webview` host API exposes the playing playlist but not a
direct path or index for its currently playing item. `getFormattedText()` may
follow playlist focus according to foobar2000's Selection Viewers preference.

The panel combines a guarded exact path with an adjacent-playlist fallback.
Default sequential playback and manual track activation are supported. Random,
shuffle, playback queue jumps, and unusual playlist mutations still need focused
testing because an adjacent item is not always the actual next item.

## AMLL CSS class coupling

Translation and romanization are hidden using classes generated by the current
AMLL release (`FmKaba_*`). A dependency upgrade may rename them. If toggles stop
working after an upgrade, inspect the generated AMLL DOM and update selectors in
`src/style.css`.

## Sidecar naming and priority

A `.ttml` or `.lrc` file must have the same basename as the audio file. TTML has
priority; LRC is only used when TTML cannot produce lyric lines. Embedded lyrics
and differently named sidecars are not implemented.

Standard LRC has line timing only. It cannot reproduce TTML word-by-word timing,
background vocals, or structured translation/romanization metadata.

## Artwork permissions

Embedded artwork can be returned directly. External artwork paths require the
WebView **Read files** permission for `readImage()`. Without it, the code falls
back to a file URI, which may still be restricted by WebView2 configuration.

## Font availability

The UI requests SF Pro first, but does not redistribute Apple's font file. On a
machine without SF Pro installed, it falls back to the system UI font.

## Performance invariants

The following rules prevent previously observed lag and state corruption:

- Do not call `setLyricLines()` from sliders or visibility toggles.
- Do not re-read TTML when a visual setting changes.
- Do not poll and replace lyrics based only on the selected playlist item.
- Do not prioritize an adjacent-track guess over an exact playing path.
- Do not load external Vite asset files in the distributed template.
