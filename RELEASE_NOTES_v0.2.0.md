# AMLL foobar2000 Panel v0.2.0

This release expands lyric display customization and sidecar compatibility.

## Highlights

- Left, center, and right lyric alignment.
- Active lyrics positioned near the upper quarter of the panel.
- Adjustable inactive-line opacity and line spacing.
- Automatic LRC fallback when TTML is missing or invalid.
- Apple Music TTML songwriter credits at the end of the lyric view.
- Wider internal lyric content without changing normal word wrapping.
- Clear, unblurred songwriter credits.

## Installation

Install `foo_uie_webview`, extract the release archive, and select the included
`index.html` as the WebView template. See `INSTALL.md` for the complete steps.
